1. The Core Transformation

Why traditional file search fails and how intelligent ingestion solves it.

Traditional Keyword Search

Rigid Text Matching

  • • Duplicate candidates created whenever a candidate re-applies with a slightly updated resume file.
  • • Misses qualified candidates if they use "React/TypeScript Lead" instead of your exact query term "Frontend Engineer".
  • • Requires tedious manual data entry for candidate names, phone numbers, and work experience.
Candidate Intelligence System

Semantic Concept Intelligence

  • • SHA-256 Fingerprinting: Prevents duplicate files instantly before parsing begins.
  • • Entity Resolution: Automatically merges new resumes into existing candidate records by email or phone.
  • • Hybrid AI Search: Combines precise keyword rules with 3D concept maps so relevant candidates are never missed.

2. How Resume Uploading Works (Ingestion Pipeline)

When a file is uploaded, 5 precise automated steps transform raw text into structured intelligence.

Resume Ingestion Flow

Step 1 & 2

Digital Fingerprinting

Before extracting text, the system calculates a unique SHA-256 cryptographic hash of the document bytes. If the file is already stored in the Content Addressable Storage (CAS), it skips re-parsing.

Step 3 & 4

Entity Resolution

Pulls names, emails, and phone numbers. If a candidate already exists in the database with the same email or phone, the new resume version is linked to their profile card automatically.

Step 5

Vector Embedding

The resume text is divided into section-aware chunks and mapped into numerical vector coordinates in an embedded LanceDB vector database for semantic search.

3. How Resume Searching Works (Hybrid Ranking)

Combining strict SQL filters with AI semantic similarity vectors for maximum precision.

Hybrid Search & Ranking Architecture

Mental Model: The "Meaning Map" Analogy

Think of traditional keyword search as a strict index card box—if a resume doesn't have the exact word typed, it gets ignored.

In Candidate Intelligence, every candidate is pinned onto a 3D Map of Ideas. Searching for "Machine Learning Architect" places a search pin on the map. The system simply measures which candidate profile pins are physically closest to your search pin, scoring their match percentage automatically.
